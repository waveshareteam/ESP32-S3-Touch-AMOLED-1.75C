# Firmware Artifacts

`Firmware/` contains checked-in factory or recovery firmware binaries for the board. These files are not generated by CI and are not treated as source projects.

The ESP-IDF and Arduino workflows currently perform compile validation only. They do not publish flashable source-built release archives yet.

When release packaging is added, generated archives should stay out of source control and should include:

- a manifest with project, target, framework, and version metadata,
- binaries under a stable archive directory,
- flash offsets or flash arguments,
- simple POSIX shell and Windows batch flash helpers.

CI should upload generated source-built archives as workflow artifacts only for maintained first-party source builds. It should not re-upload checked-in factory binaries as if they were generated outputs.
